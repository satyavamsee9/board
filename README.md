# board

The web page for a Claude Code session board that runs on your own Mac.

This page holds no data. When it's opened, the browser reads the sessions from the board server on
that same Mac (`http://127.0.0.1:7801`), using a key that only that Mac has, and nothing leaves it.
Anyone else who opens the page sees an empty "connect to your board" screen.

`index.html` is published from the (private) board code; don't edit it here.
